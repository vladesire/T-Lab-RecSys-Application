# Research questions

The study compares automatic temporal feature selection with a fixed manual gradient-boosting baseline. Related questions concern compact versus full representations, hard windows versus matched decays, and the effect of pair features on repeat versus novel targets.

- `hypotheses/`: questions, estimands and decision rules.
- `branches/`: shared experiment structure; branches do not imply independent samples.
- `decisions/`: recorded design and interpretation decisions.
- `design.yaml`: temporal feature dictionary and search design.

The current measurements are in [study.json](../evidence/submission/study.json) and [final.json](../evidence/submission/final.json). The [paper](../reports/submission/main.pdf) gives the scientific interpretation. Earlier records describe the state at their recording time; later results supersede earlier availability statements.
